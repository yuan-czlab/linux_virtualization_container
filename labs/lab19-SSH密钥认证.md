# Lab19：SSH 密钥认证

> 课时：2 | 类型：个人 | 前置：Lab18

## 一、实验步骤

### 步骤1：生成密钥对

```bash
ssh-keygen -t ed25519 -C "student@rocky-vm"
# 回车用默认路径 → 输入私钥密码（可选，生产建议设）

ls -l ~/.ssh/
# id_ed25519         私钥（权限 600）
# id_ed25519.pub     公钥

cat ~/.ssh/id_ed25519.pub
```

### 步骤2：分发公钥

```bash
ssh-copy-id student@localhost     # 输入密码
cat ~/.ssh/authorized_keys        # 公钥被添加在这里
chmod 600 ~/.ssh/authorized_keys
```

### 步骤3：验证免密登录

```bash
ssh student@localhost             # 不再要求密码！
exit
```

### 步骤4：权限故障排查

密钥认证失败 90% 是权限问题。**正确权限要求**：

| 文件/目录 | 正确权限 |
|-----------|---------|
| 家目录 ~/ | 700 或 750 |
| ~/.ssh/ | 700 |
| ~/.ssh/authorized_keys | 600 |
| ~/.ssh/id_ed25519（私钥） | 600 |

```bash
# 常见错误：私钥权限太宽松
chmod 644 ~/.ssh/id_ed25519
ssh student@localhost
# @@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@
# @  WARNING: UNPROTECTED PRIVATE KEY FILE!  @
# Permissions 0644 for 'id_ed25519' are too open.
chmod 600 ~/.ssh/id_ed25519       # 修复
```

### 步骤5：ssh-agent 缓存密码

```bash
eval $(ssh-agent)                 # 启动 agent
ssh-add ~/.ssh/id_ed25519         # 添加私钥（输入一次密码）
# 之后 ssh 不再问私钥密码
ssh-add -l                        # 查看已缓存的密钥
```

## 七、常见问题

**Q: 私钥密码（passphrase）要不要设？**
A: 生产环境强烈建议设。万一私钥文件泄露，有密码还能挡一挡。配合 ssh-agent 缓存密码，不用每次都输入。

**Q: authorized_keys 里能放多个公钥吗？**
A: 能，一行一个。每个人用自己的密钥对，谁走了删掉对应的那一行就行，不用共享私钥。

**Q: 换了台电脑怎么登录？**
A: ① 生成新密钥对，把新公钥加到服务器 authorized_keys（推荐，每台设备各自管理密钥）；② 把旧私钥安全复制到新电脑（不推荐，私钥不应该跨设备传输）。

**Q: 密钥认证失败，ssh -v 看到 "Authentication refused: bad ownership or modes"？**
A: 检查四个位置的权限：家目录(700/750)、.ssh(700)、authorized_keys(600)、私钥(600)。任何一个权限太宽松都会导致 sshd 拒绝使用。
