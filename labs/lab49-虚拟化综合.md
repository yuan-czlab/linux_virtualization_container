- `lab-iso`：隔离网络，10.10.10.0/24，DHCP 100-150

用 virt-install 或 virt-manager 创建一台 Rocky Linux VM：
- 主机名：kvm-test-01
- 内存：1GB，CPU：1 核
- 磁盘：10GB qcow2

## 七、常见问题

**Q: 虚拟化综合实验中最容易出错的环节？**
A: ①网络配置（IP 冲突、网段不一致）；②权限问题（libvirtd 未启动、用户不在 libvirt 组）；③磁盘空间不足。

**Q: KVM VM 的磁盘文件可以直接复制给其他人用吗？**
A: 可以，但需要先 sysprep（清除 SSH host key、machine-id、网络配置等个性化信息），否则两台 VM 会有相同的标识，导致各种诡异问题。
