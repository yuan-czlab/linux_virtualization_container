# 课程衔接与内容调整

> 调整原则：保留五模块、18周、144学时主框架；前9周完成《Linux操作系统》72学时，后9周完成《虚拟化容器技术》72学时。

## 一、课程关系

### 先修课程

- 大一上：C语言程序设计、Web前端、计算机组成原理。
- 大一下：Python程序设计、计算机网络技术、数据库原理及应用（MySQL）。

### 同学期课程

- 交换路由技术：使用eNSP完成交换机、路由器、VLAN和路由协议等网络设备配置。
- Python自动化运维：学习Python运维工具、远程执行、批量管理和自动化任务。

《Python自动化运维》以Paramiko、Ansible和Fabric为主。本课程不重复讲这些工具，而负责准备SSH密钥、规范主机名、IP规划、可识别的退出码和结构化巡检输出。

## 二、两门课程的职责边界

| 知识域 | 本课程群重点 | 其他课程承担 |
|---|---|---|
| 程序设计 | Shell命令组合、简单巡检与备份脚本、退出码和日志 | C/Python基础语法由先修课完成；Python自动化工具由并行课完成 |
| Web | Nginx部署、反向代理、HTTPS、日志与容器化 | HTML/CSS/JavaScript页面开发由Web前端课完成 |
| 网络 | Linux网卡、SSH、DNS客户端、端口、防火墙、SELinux和服务排障 | 交换机、路由器、VLAN、动态路由由交换路由技术完成 |
| 数据库 | MySQL/MariaDB安装、安全、账号权限、日志、备份恢复和容器化 | SQL、表设计、查询和数据库原理由先修课完成 |
| 自动化 | 提供Linux主机、SSH、服务、日志、API和Docker等被管理对象 | Python批量巡检、远程执行及自动化框架由并行课完成 |

## 三、参考培训大纲后的调整

### 保留并强化

1. Linux命令、用户权限、软件包、systemd与日志。
2. SSH、DNS解析、端口、防火墙、SELinux和网络排障。
3. Nginx、MySQL/MariaDB、Redis、Git、Shell和备份恢复。
4. VMware、KVM、快照克隆、虚拟网络与多机环境。
5. Docker、Dockerfile、Compose、数据卷、网络和综合排障。

### 新增或提高权重

- 磁盘和文件系统识别、容量告警、归档备份与恢复验证。
- `rsync + crontab`增量备份、journal日志和logrotate概念。
- 数据库最小权限、监听地址、端口暴露和恢复验证。
- Shell退出码、标准输出/错误输出、幂等意识和结构化巡检结果。
- ESXi/vCenter企业虚拟化架构认知。
- Docker健康检查、资源限制、镜像标签、Registry/Harbor概念、配置与敏感信息分离。

### 仅作认知或教师演示

- DHCP/DNS服务器、Apache/Tomcat、NFS/iSCSI。
- LVS/Keepalived、Zabbix/Prometheus、Jenkins。
- Harbor实际运维、Kubernetes、ELK/EFK、云厂商复杂产品。

这些技术出现在岗位能力地图中，但不挤占本学期核心实验课时。

## 四、建议的跨课程协同任务

以三台Linux虚拟机作为共同实验环境：

1. 《交换路由技术》完成网络拓扑、VLAN或路由连通。
2. 《Linux操作系统》完成主机配置、SSH、防火墙、Nginx、MySQL/Redis与日志排障。
3. 《Python自动化运维》通过SSH批量采集CPU、内存、磁盘、服务和端口状态。
4. 《虚拟化容器技术》将应用改造成Docker Compose部署，并加入健康检查和数据持久化。

最终共同交付拓扑图、IP规划表、部署文档、自动化巡检结果、Compose文件和故障排查报告，避免三门课程各做一套互不关联的小实验。

## 五、暂不改变的内容

- 五模块结构不变。
- 总课时144学时、18周、每周8学时不变；严格按前9周Linux、后9周虚拟化容器分段实施。
- Rocky Linux 9主线与Ubuntu Server对照不变。
- 阶段项目和综合项目的基本形式不变。
- Kubernetes、OpenStack和高级DevOps仍不作为本课程考核内容。
