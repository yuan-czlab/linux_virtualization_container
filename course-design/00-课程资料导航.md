# 课程资料导航与版本说明

> 当前状态：《Linux操作系统》与《虚拟化容器技术》两门64学时课程均已建立正式结构
>
> 主线环境：Windows 10/11 + VMware Workstation + Rocky Linux 9 + Ubuntu Server 22.04

## 一、授课顺序

```text
第一阶段：《Linux操作系统》
8周 × 8学时 = 64学时，20个实验
        ↓
第二阶段：《虚拟化容器技术》
8周 × 8学时 = 64学时，11个实验
```

两门课每周均按`2学时 + 4学时 + 2学时`三次到课组织。实验是完整项目，可以跨越多次课；课程进度表负责把实验映射到24次到课，不把实验手册机械拆分。

## 三、《Linux操作系统》资料链

1. 以`04-Linux操作系统-64学时实验项目索引.md`确定20个实验及学时边界。
2. 按`05-Linux操作系统-8周课程进度表.md`实施8周24次到课。
3. 使用`../labs/linux/`中的详细实验手册组织学生实践、验证、排障和提交。
4. 使用`../textbooks/01`至`03`讲授三个模块的原理与系统知识。
5. 使用`06-Linux操作系统-64学时知识图谱.xmind`完成课程导入和阶段复盘。

Linux课程以Rocky Linux为服务器主线，以Ubuntu Server为客户端和发行版对照；Nginx、MySQL、MongoDB和Redis均为模块三正式内容。

## 四、《虚拟化容器技术》资料链

1. 以`07-虚拟化容器技术-64学时实验项目索引.md`确定两个模块、11个实验及学时边界。
2. 按`08-虚拟化容器技术-8周课程进度表.md`实施8周24次到课。
3. 使用`../labs/virtualization-container/`中的详细实验手册组织实践与验收。
4. 使用`../textbooks/04-虚拟化容器技术-模块一-服务器虚拟化与云资源基础.md`讲授模块一。
5. 使用`../textbooks/05-虚拟化容器技术-模块二-Docker容器化应用构建与交付.md`讲授模块二。
6. 使用`09-虚拟化容器技术-64学时知识图谱.xmind`完成课程导入和复盘。

| 模块 | 学时 | 实验 | 关键内容 |
|---|---:|---|---|
| 服务器虚拟化与云资源基础 | 24 | 实验1—5 | 嵌套虚拟化、KVM、qcow2、虚拟网络、OpenStack体验 |
| Docker容器化应用构建与交付 | 40 | 实验6—11 | Rocky/Ubuntu Docker、离线镜像、网络与卷、Dockerfile、Compose、Kubernetes体验 |
| **合计** | **64** | **11个实验** |  |

OpenStack和Kubernetes均为正式操作内容：学生连接教师预建平台完成基础对象生命周期，但不在本课程部署平台或集群。

## 五、环境与资源规则

1. KVM为全员真实实验。学生在VMware中的Rocky Linux虚拟机内启用嵌套虚拟化并创建KVM客户机。
2. Docker在Rocky Linux和Ubuntu Server中均完成安装，后续用同一镜像和项目验证跨发行版交付，不重复讲两套完整命令。
3. Windows不要求安装Docker Desktop，也不把WSL作为课程前置条件。
4. Docker镜像以学校课程Registry为主通道，以U盘或共享目录中的`docker save`归档为回退通道。
5. 每批镜像必须有固定标签、镜像摘要、适用架构、文件SHA-256、镜像清单和导入说明。
6. OpenStack和Kubernetes账号、配额、Namespace、课程镜像和清理规则由教师课前统一准备。
7. 密码、私钥、Token、kubeconfig和真实数据库转储不得进入公开提交。

## 六、大项目与旧资源

现行课程只保留`labs/linux/`和`labs/virtualization-container/`两套正式实验，不再设置独立的`projects`目录。

大项目并未取消：虚拟化容器实验10完成四服务Compose项目前置成果，实验11以8学时完成Kubernetes体验、跨Rocky/Ubuntu迁移、离线镜像交付、数据恢复、综合排障和个人答辩。实验11就是期末综合大项目，避免维护重复版本。

## 七、维护与交付检查

课程内容调整时，先修改相应课程的实验项目索引，再同步进度表、实验手册、模块教材和XMind。所有关键操作后应提供预期结果、判断标准或验收点；网络、SSH、防火墙、镜像、数据卷和平台资源变更应保留回退路径。

交付给教师或学生前检查：

- `course-design`编号应从00到09连续，共10个正式文件；
- 两份XMind均应能用XMind正常打开；
- Linux课程应为20个实验、64学时和24次到课；
- 虚拟化容器课程应为11个实验、64学时和24次到课；
- 项目中不应包含XMind生成程序、校验程序或导图导入源。
