# 课程资料导航与版本说明

> 当前版本：v3.1｜适用：大二上学期｜Rocky Linux 9主线 + Ubuntu Server 22.04 LTS对照｜前9周Linux、后9周虚拟化容器

## 一、排课时以谁为准

出现表述差异时按以下优先级处理：

1. `04-18周课程进度表.md`：周次、单元、实验和项目的最终排课依据。
2. `01-unit-index.md`：U01-U72的名称、范围和核心内容。
3. `11-教学大纲.md`：课程定位、目标、边界和考核原则。
4. `14-课堂实施与理论讲授指南.md`：每个单元的理论、演示、易错点和检查问题。
5. `labs/`与`projects/`：具体操作资源，可按核心/拓展/条件实验选择。

`02-xmind-import.md`是详细知识点资源池，不承担排课功能；其中内容可用于备课和扩展讲授。

## 三、实验资源使用原则

- Lab01-Lab63是资源池，不等于63个实验必须全部独立占用一次课。
- 核心实验完成关键步骤、独立任务和验收点。
- 合并实验只选与本单元直接相关的场景，其余作为课后拓展。
- Lab43-Lab45和Lab49依赖嵌套虚拟化，属于条件/选做实验。
- Lab63跨U52和U72分阶段完成，不要求一节课导出三台完整OVA。

## 四、生成文件

执行以下命令可从最终Markdown重新生成XMind：

```powershell
python course-design\generate_course_xmind.py
python course-design\generate_module_xminds.py
python course-design\validate_course.py
```

生成后应检查总览XMind包含U01-U72，五模块XMind单元数分别为12、12、12、16、20。

## 五、维护规则

1. 调整单元时先改`04`和`01`，再同步`11`与`14`。
2. 调整实验映射时同步实验前置、项目说明和XMind。
3. 不在多个文件中复制同一份大段代码；可运行项目代码放在`projects/`实际目录中。
4. 带密码的示例只能使用实验密码，不提交真实账号、私钥和Token。
5. 每学期开课前按`16`完成一次真实环境演练。
