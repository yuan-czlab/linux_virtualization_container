# 五模块详细XMind

这些文件由 `../generate_module_xminds.py` 根据最终版教学单元索引、18周进度表和理论讲授指南生成。

每个教学单元包含：

1. 学习目标与知识范围
2. 原理与讲授重点
3. 关键命令或操作
4. 实验与成果
5. 排障、安全与检查

## 文件

- `M1-Linux基础运维-详细知识图谱.xmind`：U01-U12，24学时
- `M2-网络、远程管理与基础防护-详细知识图谱.xmind`：U13-U24，24学时
- `M3-企业服务部署与Linux阶段项目-详细知识图谱.xmind`：U25-U36，24学时
- `M4-虚拟化与多机环境-详细知识图谱.xmind`：U37-U52，32学时
- `M5-Docker容器化与综合项目-详细知识图谱.xmind`：U53-U72，40学时

修改 `01-unit-index.md`、`04-18周课程进度表.md` 或 `14-课堂实施与理论讲授指南.md` 后，执行：

```powershell
python course-design\generate_module_xminds.py
```

生成脚本会检查U01-U72、进度映射、理论内容和命令清单是否完整。
