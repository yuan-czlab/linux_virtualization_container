# 《Linux操作系统》64学时实验项目索引

> 适用专业：高职计算机应用技术专业  
> 课程性质：C类实践课程  
> 总学时：64学时（8周 × 8学时/周）  
> 学时口径：1学时为45分钟  
> 上课节奏：每周2学时 + 4学时 + 2学时  
> 主线环境：Windows 10/11 + VMware Workstation + `rocky-server` + `rocky-web` + Ubuntu 22.04 Desktop `ubuntu-client`

## 一、课程组织原则

课程按“模块—实验项目—项目任务”组织，不再将一次到课机械对应一个独立项目。

- 每个实验项目是一个完整的工作任务，可安排2、4或6学时。
- 实验手册连续编写，不按具体课次拆分“第一阶段、第二阶段”。
- 授课计划负责把实验内容分配到每周三次课中。
- Textbooks负责系统讲解知识、原理和方法，实验手册负责引导学生完成操作、验证、排障和交付。
- 实验1—19为任务型实验，实验20为课程综合项目。
- 每个实验必须形成可检查的结果，不能以“命令没有报错”作为完成标准。

### 状态与快照主线

```text
Linux-L0（实验1：三机初装）
→ Linux-L1（实验7：基础管理）
→ Linux-L2（实验13：网络、SSH与基础防护）
→ Linux-L3（实验19：企业服务与巡检）
→ Linux-L4（实验20：综合交付，也是《虚拟化容器技术》的唯一正式起点）
```

实验8生成的`~/m1-project/course-env.sh`是后续实验共享的地址参数文件，应随Linux-L2及以后快照保留。机房还原后先恢复对应快照或教师基线，再核对该文件和三机连通性；不能跳过恢复检查，直接执行依赖前序对象的实验。

## 二、课程能力主线

```text
认识Linux与虚拟化实验环境
→ 管理文件、账号、软件和服务
→ 配置网络与远程管理
→ 实施备份和基础防护
→ 部署Nginx、MySQL、MongoDB和Redis
→ 使用Git和Shell支持运维
→ 完成综合部署、故障排查与项目交付
```

## 八、内容边界

### 本课程重点

- Linux服务器安装、初始化和日常管理。
- 文件、账号、权限、软件包、systemd、日志、磁盘持久挂载、LVM基础和系统状态。
- Linux网络配置、SSH、备份、firewalld、SELinux和访问排障。
- Nginx、MySQL、MongoDB和Redis的部署、安全、日志及基础恢复。
- Git项目获取与版本恢复、Shell单机巡检。
- 综合部署、验证、故障排查、文档和答辩。

### 本课程不深入

- Linux内核编程和内核源码分析。
- 完整Shell编程语言体系和复杂脚本框架。
- SQL系统教学、数据库设计与高级查询。
- MySQL主从、高可用和性能调优。
- MongoDB复制集、分片和复杂聚合。
- Redis哨兵、集群和高级数据结构。
- Ansible、Paramiko和Fabric批量自动化。
- Docker、虚拟机管理和容器编排的系统教学；这些由后续《虚拟化容器技术》承担。
