| 项目 | 验证内容 | 当前状态 | 失败时回退方案 |
|---|---|---|---|
| Rocky Linux 9镜像 | 安装、NAT、open-vm-tools、清华/阿里源 | 待实机验证 | 使用教师已验证OVA模板 |
| Ubuntu Server 22.04镜像 | Subiquity安装、OpenSSH、apt镜像源 | 待实机验证 | 提供预装对照VM |
| 软件源 | dnf/apt安装Nginx、MariaDB、Redis等 | 待实机验证 | 教师机提供缓存或离线包 |
| Docker环境 | Engine、Compose、课程全部镜像 | 待实机验证 | 离线tar包和安装脚本 |
| 三机资源 | 3台VM同时运行时的CPU、内存和磁盘 | 待抽测 | 降低内存、两人共享三机 |

## P1：第一轮教学前建议完成

- [ ] 每个模块至少选择一台学生机完整走通核心实验。
- [ ] 对Lab21、Lab41、Lab46、Lab56、Lab62、Lab63进行90分钟计时演练。
- [ ] 验证故障注入脚本均有安全的恢复方法，不破坏学生唯一环境。
- [ ] 为所有需要联网的命令准备离线替代路径。
- [ ] 统一学生账号、实验密码规则、IP网段和主机名模板。
- [ ] 验证Project01可以在U33-U36完成，Project02可以在U69-U72恢复并交付。
- [ ] 准备项目自动验收输出，减少只依赖人工截图。

## P2：大二下衔接前完成

- [ ] 测试eNSP Cloud节点与VMware VMnet/物理网卡的连接方式。
- [ ] 确定大二下使用原OVA恢复还是使用统一模板重新构建。
- [ ] 将inventory.ini交给Paramiko、Ansible、Fabric课程继续使用。
- [ ] 为网络安全基础准备隔离网段、靶机和快照回滚规范。
- [ ] 为云计算应用准备K8s集群、镜像仓库和namespace配额。

6. 大二下eNSP到Linux多机环境的标准拓扑模板。
