# Vim 速查卡

> 打印给学生 | 单面A4

---

## 保命三连

| 场景 | 按键 |
|------|------|
| 进入编辑 | `i` |
| 保存退出 | `:wq` 或 `ZZ` |
| 不保存退出 | `:q!` |
| 回到Normal | `Esc`（任何时候！） |

## 三种模式切换

```
Normal ──i/a/o──→ Insert ──Esc──→ Normal
Normal ──v/V/Ctrl+v──→ Visual ──Esc──→ Normal
```

| 进入Insert | 效果 |
|-----------|------|
| `i` | 光标前插入 |
| `a` | 光标后插入 |
| `o` | 下一行新开一行 |
| `O` | 上一行新开一行 |
| `I` | 行首插入 |
| `A` | 行尾插入 |

## 移动（Normal模式）

| 按键 | 效果 |
|------|------|
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` | 下一词开头 |
| `b` | 上一词开头 |
| `e` | 单词结尾 |
| `0` | 行首 |
| `$` | 行尾 |
| `gg` | 文件开头 |
| `G` | 文件末尾 |
| `:行号` | 跳到第N行 |
| `Ctrl+f` | 翻下一页 |
| `Ctrl+b` | 翻上一页 |

## 编辑（Normal模式）

| 按键 | 效果 | 记忆 |
|------|------|------|
| `x` | 删光标字符 | 擦除 |
| `dd` | 删整行 | delete |
| `3dd` | 删3行 | 数字重复 |
| `yy` | 复制整行 | yank |
| `3yy` | 复制3行 | |
| `p` | 粘贴到后 | paste |
| `P` | 粘贴到前 | |
| `u` | 撤销 | undo |
| `Ctrl+r` | 重做 | redo |
| `dw` | 删一个词 | delete word |
| `cw` | 改一个词 | change word |
| `ciw` | 改光标所在词 | change inner word |
| `>>` / `<<` | 缩进/反缩进 | |

## 搜索替换

| 操作 | 命令 |
|------|------|
| 向下搜索 | `/关键词` |
| 向上搜索 | `?关键词` |
| 下一匹配 | `n` |
| 上一匹配 | `N` |
| 取消高亮 | `:noh` |
| 全局替换 | `:%s/old/new/g` |
| 确认替换 | `:%s/old/new/gc` |
| 当前行替换 | `:s/old/new/g` |
| 第3-10行替换 | `:3,10s/old/new/g` |

## 窗口管理

| 命令 | 效果 |
|------|------|
| `:split 文件` | 水平分屏 |
| `:vsplit 文件` | 垂直分屏 |
| `Ctrl+w h/j/k/l` | 切换窗口 |
| `Ctrl+w q` | 关闭当前窗口 |
| `:only` | 只保留当前窗口 |

## 常用设置（~/.vimrc）

```vim
set number          " 显示行号
set tabstop=4       " Tab宽度
set expandtab       " Tab转空格
set hlsearch        " 搜索高亮
set ignorecase      " 搜索忽略大小写
syntax on           " 语法高亮
```

## 快速记忆

```
Normal模式 = 浏览+发命令（默认状态）
i = 开始打字（Insert模式）
Esc = 回到Normal（万能的Esc键）
:wq = 下班
:q! = 不干了
```
