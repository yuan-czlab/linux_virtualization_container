# 《Linux操作系统》与《虚拟化容器技术》课程教学大纲（项目化版本）

> 适用专业：高职计算机应用技术专业（云计算与运维方向 / 网络运维方向）  
> 适用年级：大二上学期  
> 课程形态：教务上分为《Linux操作系统》和《虚拟化容器技术》两门课；教学实施上按一条连续课程链组织  
> 建议总学分：8 学分  
> 建议总学时：128—144 学时  
> 建议主线系统：Rocky Linux 9  
> 建议对照系统：Ubuntu Server 24.04 LTS  
> 建议教学方式：Markdown 讲义 + 知识地图 / XMind + 终端演示 + 项目任务单

---

## 一、课程设置背景

随着云计算、容器化部署、自动化运维和智能运维的发展，传统计算机应用技术专业中的单一“操作系统基础”课程已经难以支撑学生后续学习企业项目运维、云计算应用、网络安全基础和智能体开发实战等课程的需要。

从岗位能力看，初级运维、云计算运维助理、系统实施工程师、项目部署工程师等岗位通常要求学生具备 Linux 系统管理、网络服务访问、Web 服务部署、数据库与中间件基础维护、虚拟化环境搭建、Docker 容器部署、日志查看、基础故障排查和运维文档编写等能力。

因此，本课程群将《Linux操作系统》和《虚拟化容器技术》作为连续课程链进行设计，按照“Linux服务器管理 → 网络与远程管理 → 企业常见服务部署 → 虚拟化多机环境 → Docker容器化部署 → 综合运维项目”的顺序组织教学，突出项目化、任务化和岗位化。

---

## 二、课程定位

本课程群是计算机应用技术专业云计算与运维方向的专业核心基础课程，主要面向 Linux 运维、云计算运维、系统实施、项目部署、网络运维辅助和智能运维平台应用等岗位需求。

课程以 Linux 服务器基础管理为起点，以网络服务部署与故障排查为核心，以虚拟化环境搭建和 Docker 容器化应用部署为实践载体，培养学生完成服务器安装配置、远程管理、服务运行维护、数据库与中间件部署、虚拟机管理、容器编排、日志分析、基础故障排查和运维文档编写的能力。

课程不定位为 Linux 内核原理课程，也不定位为 Kubernetes、OpenStack 或高级 DevOps 课程。本课程的重点是帮助学生建立后续学习企业级项目运维、云计算应用、网络安全基础和智能体开发实战所需要的运维底座能力。

## 三、课程总目标

学生完成本课程群学习后，应能够独立完成一套中小型企业基础运维环境的搭建与容器化部署，包括 Linux 服务器安装配置、网络与远程管理、Web 服务部署、数据库与中间件运行维护、虚拟化多机环境搭建、Docker Compose 多服务部署、基础故障排查和运维文档编写。

### 3.1 知识目标

1. 理解 Linux 操作系统在服务器、云计算和运维岗位中的作用。
2. 理解 Rocky Linux、Ubuntu Server、CentOS、RHEL 系发行版之间的关系。
3. 掌握 Linux 文件目录、用户权限、软件包管理、服务管理和日志管理的基本知识。
4. 掌握 IP、端口、DNS、SSH、HTTP/HTTPS、防火墙等 Linux 运维常见网络知识。
5. 理解 Nginx、MySQL/MariaDB、Redis、Git 等常见企业服务和工具在运维部署中的作用。
6. 理解虚拟化、虚拟机、快照、克隆、虚拟网络与云服务器之间的关系。
7. 理解 Docker 镜像、容器、数据卷、网络、Dockerfile 和 Docker Compose 的基本概念。
8. 理解服务访问故障、端口不通、DNS 解析异常、容器启动失败等常见问题的排查思路。

### 3.2 能力目标

1. 能够安装和初始化 Rocky Linux / Ubuntu Server 系统。
2. 能够使用 Linux 常用命令完成文件、目录、用户、权限、软件包和服务管理。
3. 能够配置 IP、主机名、DNS、SSH、防火墙，完成远程连接与访问测试。
4. 能够部署 Nginx、MySQL/MariaDB、Redis 等常见服务，并完成基础连接测试和日志查看。
5. 能够使用 Git 获取项目代码，理解 Git 在项目部署中的作用。
6. 能够编写简单 Shell 脚本完成巡检、服务检查、日志检索和备份等基础任务。
7. 能够创建、快照、克隆虚拟机，并搭建多台 Linux 服务器互通环境。
8. 能够安装 Docker，运行和管理容器，配置端口映射、数据卷和容器网络。
9. 能够编写基础 Dockerfile，使用 Docker Compose 部署 Web + MySQL + Redis 等多服务应用。
10. 能够按照“IP → 网络 → 服务 → 端口 → 防火墙 → 日志 → 容器映射”的路径排查常见故障。
11. 能够编写 IP 地址规划表、部署文档、排障记录和综合运维报告。

### 3.3 素质目标

1. 培养学生规范操作服务器、重视权限和安全边界的职业意识。
2. 培养学生遇到故障时按流程排查、记录过程和复盘总结的工程习惯。
3. 培养学生遵守最小权限、端口最小开放、数据备份和日志留痕等运维规范。
4. 培养学生团队协作、任务交付、技术文档编写和项目答辩表达能力。
5. 培养学生面向云计算、自动化运维和智能运维方向持续学习的意识。

## 四、课程设计依据

本课程内容设计主要参考以下依据：

1. Linux Foundation 对 Linux 系统管理员能力的描述强调命令行环境下的真实系统管理任务，并将 Operations and Deployment、Networking、Storage、Users & Groups、Essential Commands 等作为核心能力域。
2. 主流 DevOps 学习路线通常将 Linux、网络、Git、脚本、服务管理、容器、CI/CD、监控和云平台作为递进能力链。
3. Docker 官方文档将 Docker 定位为用于构建、共享和运行容器化应用的平台，Docker Compose 用于通过 YAML 文件管理多容器应用中的服务、网络和数据卷。
4. 国内运维岗位招聘要求中高频出现 Linux、Nginx、MySQL、Redis、DNS、Shell/Python、虚拟化、Docker、日志、监控、备份、项目部署等技术关键词。

因此，本课程重点放在 Linux 服务器基础管理、网络服务部署、常见服务运行维护、虚拟化实验环境搭建和 Docker Compose 项目部署上；Jenkins、Ansible、Prometheus/Grafana、ELK、Kubernetes、云厂商产品和安全攻防等内容仅作了解或后续课程衔接，不在本课程深入展开。

## 六、模块一：Linux基础运维

### 6.1 模块目标

通过本模块学习，学生能够认识 Linux 在服务器和运维岗位中的作用，能够安装 Linux 系统，掌握命令行基础、文件目录管理、用户权限管理、软件包管理和基础服务管理方法。

### 6.2 教学内容

#### 6.2.1 Linux与运维岗位认知

- Linux 是什么。
- Linux 内核与 Linux 发行版。
- Rocky Linux、Ubuntu Server、CentOS、RHEL 的关系。
- 为什么课程主线建议使用 Rocky Linux，Ubuntu Server 作为对照。
- Linux 在服务器、云计算、网络运维和智能运维中的作用。
- 初级 Linux 运维岗位的典型工作任务。

#### 6.2.2 Linux安装与基础使用

- 在虚拟机中安装 Rocky Linux。
- root 用户与普通用户。
- 命令行终端的基本使用。
- 命令格式、参数、选项。
- 帮助命令：`man`、`--help`、`history`。
- 基础命令：`pwd`、`ls`、`cd`、`clear`、`whoami`、`hostname`。

#### 6.2.3 文件、目录与文本编辑

- Linux 目录结构：`/etc`、`/var`、`/home`、`/usr`、`/opt`、`/tmp`。
- 文件与目录操作：`touch`、`cp`、`mv`、`rm`、`mkdir`。
- 文件查看：`cat`、`less`、`head`、`tail`。
- 文件查找：`find`、`which`、`whereis`。
- 文本编辑：`vim` 基础使用。
- 压缩与解压：`tar`、`zip`、`unzip`。

#### 6.2.4 用户、用户组与权限

- root 用户与普通用户的区别。
- 用户管理：`useradd`、`passwd`、`usermod`、`userdel`。
- 用户组管理：`groupadd`、`groups`、`id`。
- 文件权限：`rwx`、所有者、所属组、其他用户。
- 权限修改：`chmod`、`chown`、`chgrp`。
- `sudo` 与最小权限原则。

#### 6.2.5 软件包与基础服务管理

- Rocky Linux 软件包管理：`dnf`。
- Ubuntu Server 软件包管理对照：`apt`。
- 软件源与镜像源概念。
- systemd 与服务管理基础。
- `systemctl start/stop/restart/status/enable/disable`。
- 服务状态：active、inactive、failed。
- 基础服务案例：sshd、nginx。

|---|---|---|
| 任务1 | 安装 Rocky Linux 虚拟机 | 安装截图、系统版本截图 |

### 6.4 模块考核要点

- 能否独立安装并登录 Linux 系统。
- 能否熟练使用基础命令。
- 能否正确管理文件、目录、用户和权限。
- 能否安装软件并使用 systemctl 管理服务。

## 七、模块二：Linux网络、协议与远程管理

### 7.1 模块目标

通过本模块学习，学生能够理解 Linux 服务器如何对外提供服务，掌握 IP、端口、DNS、SSH、HTTP/HTTPS、防火墙等基础网络与协议知识，并能够完成远程管理和网络访问故障排查。

### 7.2 教学内容

#### 7.2.1 Linux网络基础

- IP 地址、子网掩码、网关、DNS。
- 网卡名称与网络接口。
- 查看网络信息：`ip addr`。
- 查看路由：`ip route`。
- 主机名配置：`hostnamectl`。
- DNS 配置文件：`/etc/resolv.conf`。
- 本地域名解析：`/etc/hosts`。
- 连通性测试：`ping`、`curl`、`wget`。

#### 7.2.2 TCP/UDP与端口

- TCP 与 UDP 的基本区别。
- 服务与端口的关系。
- 常见端口：22、80、443、3306、6379、8080。
- 查看端口监听：`ss -tunlp`。
- 端口占用与服务访问测试。
- “服务启动”和“端口可访问”的区别。

#### 7.2.3 SSH远程管理与文件传输

- SSH 在运维中的作用。
- SSH 服务：`sshd`。
- SSH 连接：`ssh 用户名@服务器IP`。
- SSH 默认端口 22。
- 密码登录与密钥登录入门。
- SSH 常见故障：连接超时、拒绝连接、密码错误、权限问题。
- 文件传输：`scp`、`sftp`、`rsync`。
- FTP 了解，不作为重点。

#### 7.2.4 HTTP/HTTPS与Nginx基础访问

- HTTP 与 HTTPS 的作用。
- 80 端口与 443 端口。
- Nginx 作为 Web 服务。
- 使用 `curl http://IP` 测试访问。
- Nginx 访问日志与错误日志。
- HTTPS 证书概念。
- 自签名证书拓展实验。

#### 7.2.5 DNS解析与基础排障

- DNS 的作用。
- 域名解析为 IP 的过程。
- `/etc/hosts` 与本地域名解析。
- `/etc/resolv.conf` 与 DNS 服务器。
- `nslookup` 或 `dig` 基础使用。
- 能访问 IP 但不能访问域名的故障分析。

#### 7.2.6 防火墙与端口开放

- 防火墙在 Linux 运维中的作用。
- Rocky Linux 防火墙：firewalld。
- 查看规则：`firewall-cmd --list-all`。
- 开放端口：`firewall-cmd --add-port=80/tcp --permanent`。
- 开放服务：`firewall-cmd --add-service=http --permanent`。
- 重载规则：`firewall-cmd --reload`。
- Ubuntu 防火墙对照：ufw。
- 数据库端口和 Redis 端口的安全开放意识。

### 7.3 网络排障流程

```text
服务访问不了
→ 虚拟机是否运行
→ IP 是否正确
→ 网络是否能 ping 通
→ DNS 是否正常
→ 服务是否启动
→ 端口是否监听
→ 防火墙是否放行
→ 日志是否报错
```

### 7.4 模块实训任务

| 任务 | 内容 | 成果 |
|---|---|---|
| 任务1 | 配置并查看 Linux IP 地址 | IP 截图 |
| 任务2 | 使用 SSH 远程连接 Linux | SSH 成功截图 |
| 任务3 | 使用 scp 或 sftp 上传文件 | 上传记录 |

| 任务6 | 开放防火墙端口并测试 | firewalld 配置截图 |

### 7.5 模块考核要点

- 能否配置和查看 IP、网关、DNS。
- 能否使用 SSH 远程连接服务器。
- 能否理解端口与服务访问的关系。
- 能否配置防火墙开放指定端口。
- 能否按流程排查网络访问失败问题。

## 八、模块三：企业常见服务部署与基础排障

### 8.1 模块目标

通过本模块学习，学生能够在 Linux 上部署和维护 Nginx、MySQL/MariaDB、Redis、Git 等企业常见服务和工具，能够查看服务状态、端口、日志，并能够编写简单 Shell 脚本完成巡检、服务检查、日志检索和备份任务。

### 8.2 教学内容

#### 8.2.1 Nginx服务部署与日志

- 安装 Nginx。
- 使用 systemctl 管理 Nginx。
- 修改默认网页。
- 开放 80 端口。
- 浏览器和 curl 访问测试。
- Nginx access.log 与 error.log。
- 常见错误：403、404、502 的初步认识。

#### 8.2.2 MySQL/MariaDB部署与基础维护

- MySQL/MariaDB 作为数据库服务的作用。
- 安装与启动数据库服务。
- 3306 端口。
- 本机连接与简单远程连接。
- 创建简单测试库。
- 数据库服务日志。
- `mysqldump` 基础备份。
- 数据库端口开放的安全风险。

不深入讲 SQL 基础、索引优化、事务原理、主从复制和高可用集群。

#### 8.2.3 Redis部署与基础测试

- Redis 的作用：缓存 / 键值服务。
- 安装或 Docker 运行 Redis。
- 6379 端口。
- `redis-cli` 简单测试。
- Redis 端口安全风险。
- Redis 与后续 Docker Compose 项目的关系。

不深入讲 Redis 高级数据结构、持久化机制、主从哨兵和集群。

#### 8.2.4 Git基础与项目获取

- Git 在项目部署中的作用。
- 安装 Git。
- `git clone`。
- `git pull`。
- `git log`。
- `git checkout` / `git switch` 简单使用。
- `.gitignore` 了解。
- GitHub、Gitee、GitLab 作为代码仓库。

不深入讲复杂分支协作、冲突解决和 Git Flow。

#### 8.2.5 系统状态、日志与排障方法

- CPU 查看：`top`、`uptime`。
- 内存查看：`free -h`。
- 磁盘查看：`df -h`、`du -sh`。
- 进程查看：`ps aux`。
- 端口查看：`ss -tunlp`。
- systemd 日志：`journalctl`。
- 服务日志：Nginx、MySQL、Redis。
- 实时日志查看：`tail -f`。
- 关键字检索：`grep error`。

#### 8.2.6 Shell基础运维脚本

- Shell 脚本格式：`#!/bin/bash`。
- 脚本执行：`bash test.sh`、`chmod +x test.sh`。
- 变量与输出：`echo`。
- 条件判断：`if`。
- 循环：`for`。
- 管道和重定向：`|`、`>`、`>>`。
- 定时任务：`crontab`。
- 系统巡检脚本。
- 服务检查脚本。
- 日志检索脚本。
- 网站目录备份脚本。

Shell 在本课程中作为 Linux 运维基本工具讲解，不作为高级 Shell 编程专题。

### 8.3 阶段项目：单机Linux服务部署与排障

#### 项目名称

单台 Linux Web 服务部署与基础排障

#### 项目任务

1. 安装并启动 Nginx。
2. 修改并发布静态网页。
3. 开放 80 端口并完成访问测试。
4. 安装并启动 MySQL/MariaDB。
5. 完成数据库连接测试和基础备份。
6. 安装并测试 Redis。
7. 使用 Git 获取项目文件。
8. 编写 Shell 巡检脚本或服务检查脚本。
9. 模拟并排查 2 个故障。
10. 编写部署文档和排障记录。

#### 阶段成果

一台可远程管理、可访问 Web 服务、可运行数据库和中间件、具备基础脚本巡检能力的 Linux 服务器。

### 8.4 模块考核要点

- 能否部署 Nginx 并完成外部访问。
- 能否部署和测试 MySQL/MariaDB、Redis。
- 能否使用 Git 获取项目代码。
- 能否查看服务日志和系统状态。
- 能否编写简单 Shell 运维脚本。
- 能否完成基础故障排查记录。

## 九、模块四：虚拟化技术与多机环境搭建

### 9.1 模块目标

通过本模块学习，学生能够理解虚拟化与云计算的关系，能够创建、安装、快照、克隆和管理多台 Linux 虚拟机，能够配置 NAT、桥接、仅主机等虚拟网络模式，并搭建小型多服务器实验环境。

### 9.2 教学内容

#### 9.2.1 虚拟化与云计算基础认知

- 什么是虚拟化。
- 物理机、虚拟机、云服务器的关系。
- Type 1 与 Type 2 虚拟化了解。
- 常见虚拟化软件：VMware、VirtualBox、UTM。
- 虚拟化为什么是云计算和运维实验环境的基础。

#### 9.2.2 虚拟机创建与Linux安装

- 创建虚拟机。
- CPU、内存、磁盘、网卡资源分配。
- ISO 镜像使用。
- 安装 Rocky Linux。
- Ubuntu Server 对照安装。
- 初始化主机名、用户和网络。

#### 9.2.3 快照、克隆与模板机

- 快照的作用。
- 快照恢复。
- 虚拟机克隆。
- 完整克隆与链接克隆了解。
- 模板机的制作。
- 实验前快照规范。

#### 9.2.4 虚拟网络模式

- NAT 模式。
- 桥接模式。
- 仅主机模式。
- 虚拟网段与 DHCP。
- IP 规划。
- 常见问题：IP 冲突、网段不一致、无法上网、宿主机无法访问虚拟机。

#### 9.2.5 多机服务器环境搭建

建议搭建三台虚拟机：

| 主机名 | 角色 | 主要用途 |
|---|---|---|
| web-server | Web服务器 | 部署 Nginx / 前端服务 |
| db-server | 数据库服务器 | 部署 MySQL / Redis |
| client | 测试客户端 | 测试访问、连通性和服务状态 |

教学内容包括：

- 三台虚拟机互通。
- 配置主机名。
- 配置 IP 地址。
- 配置 `/etc/hosts`。
- 宿主机 SSH 连接多台虚拟机。
- 绘制拓扑图。
- 编写 IP 地址规划表。

### 9.3 模块实训任务

| 任务 | 内容 | 成果 |
|---|---|---|
| 任务1 | 创建并安装 Linux 虚拟机 | 安装截图 |
| 任务2 | 为虚拟机创建快照 | 快照截图 |
| 任务3 | 克隆多台虚拟机 | 克隆结果截图 |
| 任务4 | 配置 NAT / 桥接 / 仅主机网络 | 网络配置记录 |
| 任务5 | 搭建三台服务器互通环境 | ping / ssh 截图 |
| 任务6 | 绘制拓扑图和 IP 地址规划表 | 文档成果 |

### 9.4 模块考核要点

- 能否独立创建虚拟机并安装 Linux。
- 能否使用快照和克隆保护实验环境。
- 能否理解并配置虚拟网络模式。
- 能否搭建多机互通环境。
- 能否编写 IP 地址规划表和拓扑说明。

## 十、模块五：Docker容器化部署与综合项目

### 10.1 模块目标

通过本模块学习，学生能够理解容器化技术的作用，能够安装 Docker，管理镜像与容器，配置端口映射、数据卷和容器网络，能够编写基础 Dockerfile，并能够使用 Docker Compose 部署 Web + MySQL + Redis 等多服务应用，最终完成中小型企业基础运维环境搭建与容器化部署综合项目。

### 10.2 教学内容

#### 10.2.1 容器化技术认知

- 容器是什么。
- Docker 是什么。
- 镜像与容器的关系。
- 容器和虚拟机的区别。
- 容器化解决的核心问题：环境一致、快速部署、隔离运行、便于迁移。
- Docker 在 DevOps 和云计算中的位置。

#### 10.2.2 Docker安装与基础命令

- 安装 Docker。
- Docker 服务管理：`systemctl status docker`。
- 镜像管理：`docker pull`、`docker images`、`docker rmi`。
- 容器管理：`docker run`、`docker ps`、`docker stop`、`docker restart`、`docker rm`。
- 进入容器：`docker exec -it`。
- 查看日志：`docker logs`。

#### 10.2.3 Docker端口、数据卷与网络

- 端口映射：`-p`。
- 数据卷：`-v`。
- 目录挂载。
- 数据持久化。
- bridge 网络。
- 自定义网络。
- 容器之间通信。
- 常见故障：端口冲突、卷权限问题、容器启动失败、容器网络不通。

#### 10.2.4 Dockerfile基础

- Dockerfile 的作用。
- 常见指令：`FROM`、`RUN`、`COPY`、`WORKDIR`、`EXPOSE`、`CMD`。
- 构建镜像：`docker build`。
- 运行自定义镜像。
- 自定义 Nginx 静态网页镜像案例。

不深入讲多阶段构建、镜像安全扫描和镜像仓库高级管理。

#### 10.2.5 Docker Compose多服务编排

- Docker Compose 的作用。
- YAML 格式。
- `services`。
- `ports`。
- `volumes`。
- `networks`。
- `environment`。
- `depends_on`。
- `docker compose up -d`。
- `docker compose down`。
- `docker compose ps`。
- `docker compose logs`。

#### 10.2.6 Docker部署常见服务

- Docker 部署 Nginx。
- Docker 部署 MySQL。
- Docker 部署 Redis。
- Docker 部署 MongoDB 作为拓展。
- 使用数据卷保存 MySQL 数据。
- 使用自定义网络连接 Web、数据库和缓存服务。
- 从 Git 仓库拉取项目并部署。

MongoDB 只作为 NoSQL 服务和容器化部署拓展，不深入讲数据模型。

### 10.3 综合项目

#### 项目名称

中小型企业基础运维环境搭建与容器化部署

#### 项目目标

学生以小组或个人形式完成一套基础运维实验环境，能够从 Linux 系统安装、网络远程、服务部署、虚拟化多机环境、Docker 容器化部署到故障排查和文档交付形成完整闭环。

#### 项目任务

| 阶段 | 任务 |

| 数据服务 | 部署 MySQL/MariaDB 并完成连接和备份 |

### 10.4 模块考核要点

- 能否安装 Docker 并管理容器。

- 能否使用 Docker Compose 部署多服务应用。
- 能否排查容器启动失败、端口冲突、数据卷挂载错误等问题。
- 能否完成综合项目交付和答辩。

## 十七、附：课程最终学习成果描述

学生完成本课程群后，应能够达到以下综合效果：

> 能够独立安装和管理 Linux 服务器，完成网络配置、SSH远程连接、服务部署、数据库与中间件基础维护、日志查看、Shell基础脚本编写、虚拟化多机环境搭建、Docker Compose 多服务容器化部署，并能够针对服务访问失败、端口不通、防火墙阻断、DNS异常、容器启动失败等常见问题进行基础排查，最终提交规范的部署文档、拓扑图、IP地址规划表和故障排查报告。
