# 实验环境准备清单

> 每学期开学前按此清单准备，避免上课当天发现缺环境

---

## 一、宿主机要求

| 项目 | 最低配置 | 建议配置 |
|------|---------|---------|
| 操作系统 | Windows 10/11 64位 | Windows 11 64位 |
| CPU | 4核（需支持VT-x/AMD-V） | 8核 |
| 内存 | 16GB | 32GB |
| 磁盘 | 150GB 空闲 | 256GB SSD |
| 虚拟化软件 | VMware Workstation 17 Pro | 同左 |
| 学生终端 | VS Code / Xshell / MobaXterm | 任一即可 |

## 二、安装镜像（提前放到共享目录）

| 镜像 | 文件名 | 用途 | 模块 |
|------|--------|------|------|
| Rocky Linux 9 | Rocky-9.4-x86_64-minimal.iso | 主线系统（全部实验） | M1-M5 |
| Ubuntu Server 22.04 LTS | ubuntu-22.04-live-server-amd64.iso | 对照系统 | M1 |

## 三、模块环境准备

### 模块一：Linux基础运维（第1-3周）

```
□ VMware Workstation 17 Pro 已安装
□ Rocky-9.4-minimal.iso 已就绪（放在 D:\ISO\ 或共享目录）
□ ubuntu-22.04-live-server-amd64.iso 已就绪
□ 教室投影/屏幕共享方案确认（教师终端如何投影）
□ 学生机 VMware 虚拟网络确认（NAT模式 192.168.200.0/24）
```

### 模块二：网络、远程管理与基础防护（第4-6周）

```
□ 学生 Rocky VM 已装好（模块一创建的）
□ 学生 Ubuntu VM 可用（可选对照）
□ 确认 VMware NAT 网络正常工作
□ 配置并验证清华源或阿里源；保留一份可回退的原始repo配置
□ 教师机保留课程所需RPM/DEB包或缓存，避免镜像站临时不可用
□ 教师准备好故障注入脚本（systemctl stop/防火墙规则/SELinux修改）
```

### 模块三：企业服务部署（第7-9周）

```
□ 学生 Rocky VM 干净可用（建议打快照）
□ 确认清华源或阿里源可用；不把公共互联网持续可用作为课堂前提
□ Nginx/MariaDB/Redis 能通过 dnf 正常安装
□ Git 远程仓库可用（或准备本地模拟方案）
□ 教师准备好故障注入方案：
  □ Nginx 停止
  □ 防火墙拦截
  □ SELinux 上下文修改
  □ MySQL 停止
  □ Redis 密码修改
```

### 模块四：虚拟化技术（第10-13周）

```
□ 学生宿主机 CPU 支持虚拟化（VT-x/AMD-V 在BIOS中开启）
□ 教师先抽测3-5台不同型号学生机能否开启VMware嵌套虚拟化
□ 若嵌套虚拟化验证通过，再启用：虚拟机设置 → 处理器 → 虚拟化 Intel VT-x/EPT
□ 若验证不通过，Lab43-Lab45改为教师演示/选做，不作为学生必做考核
□ KVM工具包和演示qcow2镜像由教师机离线保留
□ VMware 虚拟网络编辑器可用
□ 教师机准备好三机环境演示（或学生机上有三台VM）
□ 准备统一的web-server/db-server/client命名、IP规划和SSH清单模板
□ 明确OVA、配置仓库、数据库备份和项目文档的学期末归档位置
```

### 模块五：Docker容器化（第14-18周）

```
□ Docker Engine/Compose安装包或仓库配置由教师统一提供
□ Docker镜像获取使用教师已有方案，不依赖Docker Hub课堂可用性
□ 学生 VM 磁盘剩余空间 ≥ 20GB（镜像&容器）
□ 提前准备本课程必需镜像清单并逐一验证可获取或可离线导入
□ Docker Compose 插件已安装（docker compose 可用）
□ 教师准备好故障注入方案：
  □ docker stop 某容器
  □ 端口冲突
  □ Volume 权限问题
  □ Nginx 配置错误
```

## 四、教师机额外准备

| 项目 | 说明 |
|------|------|
| 终端投影 | VS Code 打开 Markdown 文件 + 终端全屏 |
| 命令速查 | 本文件 + 速查表 |
| 故障注入 | 提前写好脚本，一键注入多个故障 |
| 学生作业收集 | 共享目录 / 飞书 / 课堂派 |
| 实验快照 | 每个模块开始前给 VM 拍快照 |
| 软件源 | Rocky/Ubuntu镜像源配置模板 + 原始配置备份 + 必需包离线副本 |
| 跨学期归档 | 每组保存OVA、IP表、SSH清单、配置仓库、数据库备份和Compose文件 |

## 五、每节课前检查（5分钟）

```
□ 教师终端可投影
□ 学生 VM 已开机
□ 学生 VM 网络正常（ping 网关）
□ 本节课需要的软件已安装
□ 上次实验残留已清理
```

## 六、学期前一次性准备清单

```
□ ① VMware Workstation 17 Pro 安装
□ ② Rocky-9.4-minimal.iso 下载
□ ③ Ubuntu-22.04-live-server-amd64.iso 下载
□ ④ 学生机 BIOS 开启 VT-x/AMD-V
□ ⑤ 学生机 VMware 虚拟网络配好（NAT 192.168.200.0/24）
□ ⑥ 教师机装好 VS Code + Markdown 插件
□ ⑦ 教室投影/投屏测试
□ ⑧ 共享目录/作业收集方案确定
□ ⑨ 清华源/阿里源配置与回退方案验证
□ ⑩ 抽测嵌套虚拟化；确定KVM采用全员实验还是教师演示
□ ⑪ 建立跨学期项目归档目录和恢复说明
```
