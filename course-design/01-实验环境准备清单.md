# 实验环境准备清单

> 每学期开学前按此清单准备，避免上课当天发现缺环境

---

## 一、宿主机要求

| 项目 | 最低配置 | 建议配置 |
|------|---------|---------|
| 操作系统 | Windows 10/11 64位 | Windows 11 64位 |
| CPU | 4核（需支持VT-x/AMD-V） | 8核 |
| 内存 | 16GB | 32GB |
| 磁盘 | 150GB 空闲 | 256GB SSD |
| 虚拟化软件 | VMware Workstation 17 Pro | 同左 |
| 学生终端 | Ubuntu Server命令行客户端 | Windows Terminal、VS Code可作辅助 |

## 二、安装镜像（提前放到共享目录）

| 镜像 | 文件名 | 用途 | 模块 |
|------|--------|------|------|
| Rocky Linux 9 | Rocky-9.x-x86_64-minimal.iso | Linux课程服务器（实验1—20） | M1—M3 |
| Ubuntu Server 22.04 LTS | ubuntu-22.04-live-server-amd64.iso | Linux课程正式客户端 | M1—M3 |

## 三、模块环境准备

### 模块一：Linux基础运维（第1—3周）

```
□ VMware Workstation 17 Pro 已安装
□ Rocky Linux 9 minimal ISO 已就绪（放在 D:\ISO\ 或共享目录）
□ ubuntu-22.04-live-server-amd64.iso 已就绪
□ 两份ISO的SHA256已由教师校验并公布
□ 教室投影/屏幕共享方案确认（教师终端如何投影）
□ 学生机 VMware NAT网络已确认并记录实际网段、网关和DHCP范围
```

### 模块二：网络、远程管理与基础防护（第3—5周）

```
□ 学生 Rocky VM 已装好（模块一创建的）
□ 学生 Ubuntu VM 已装好，作为正式SSH、HTTP和来源限制测试客户端
□ 确认 VMware NAT 网络正常工作
□ 配置并验证清华源或阿里源；保留一份可回退的原始repo配置
□ 教师机保留课程所需RPM/DEB包或缓存，避免镜像站临时不可用
□ 教师准备好故障注入脚本（systemctl stop/防火墙规则/SELinux修改）
```

### 模块三：企业服务部署与综合运维（第6—8周）

```
□ 学生 Rocky VM 干净可用（建议打快照）
□ 学生 Ubuntu客户端可用，名称解析、curl、SSH和数据库客户端可安装
□ 确认清华源或阿里源可用；不把公共互联网持续可用作为课堂前提
□ Nginx、MySQL 8.4 LTS、MongoDB 8.0、Redis的统一仓库或离线包已验证
□ Git 远程仓库可用（或准备本地模拟方案）
□ 教师准备好故障注入方案：
  □ Nginx 停止
  □ 防火墙拦截
  □ SELinux 上下文修改
  □ MySQL 停止
  □ Redis 密码修改
```

### 《虚拟化容器技术》模块一：服务器虚拟化与云资源基础（24学时）

```
□ 学生宿主机 CPU 支持虚拟化（VT-x/AMD-V 在BIOS中开启）
□ 教师先抽测3-5台不同型号学生机能否开启VMware嵌套虚拟化
□ Windows中不会由其他虚拟化组件独占硬件虚拟化能力
□ Rocky VM建议调整为4 vCPU、6—8GB内存、80GB以上磁盘
□ VMware为Rocky VM启用嵌套虚拟化，Rocky内能看到vmx或svm
□ virt-host-validate、KVM内核模块和libvirt连接在抽测机中通过
□ KVM/QEMU/libvirt/virt-install工具包已进入统一仓库或离线目录
□ 教师轻量qcow2基础镜像已验证，带固定版本、SHA256和导入说明
□ 基础镜像为只读源，学生实验磁盘使用复制或差异镜像
□ libvirt默认NAT网络、DHCP、控制台和SSH访问均已测试
□ 同时运行Rocky宿主与1—2台轻量KVM客户机时资源可接受
□ 教师预建OpenStack平台可以从学生网络访问
□ OpenStack学生账号、Project、配额、镜像、Flavor、网络和安全组规则已准备
□ 每名学生能够创建、连接和删除至少一台轻量云主机
□ OpenStack不可用时的补做时段或统一远程环境已确定
```

### 《虚拟化容器技术》模块二：Docker容器化应用构建与交付（40学时）

```
□ Rocky与Ubuntu的Docker Engine、Compose插件仓库和离线安装包均已验证
□ Windows不要求Docker Desktop或WSL
□ Rocky与Ubuntu VM各有至少20GB剩余空间
□ 学校课程Registry已部署并可从两台Linux VM访问
□ 学生使用只读Registry账号或免认证只读课程命名空间
□ 所有镜像使用固定课程标签，不以latest作为正式验收依据
□ 镜像清单包含镜像引用、摘要、架构、归档文件和SHA256
□ 所有课程镜像均已执行一次docker pull和一次docker load验证
□ U盘或共享目录离线包包含tar、SHA256SUMS、image-manifest.csv和README
□ Web、API、MySQL、Redis、toolbox与构建基础镜像均已准备
□ Dockerfile应用素材和Compose项目模板已在Rocky、Ubuntu分别运行
□ MySQL数据卷备份、模拟丢失与恢复流程已走通
□ 教师准备好故障注入方案：
  □ docker stop 某容器
  □ 错误镜像标签
  □ 端口冲突
  □ 网络名或服务名错误
  □ Volume或绑定挂载权限问题
  □ 环境变量和健康检查错误
□ 教师预建Kubernetes集群可访问
□ kubeconfig、context、学生Namespace、RBAC和资源配额已验证
□ Kubernetes能够拉取课程固定镜像
□ Deployment、Pod、Service、日志、扩缩容和清理流程已走通
```

## 四、教师机额外准备

| 项目 | 说明 |
|------|------|
| 终端投影 | VS Code 打开 Markdown 文件 + 终端全屏 |
| 命令查阅 | 对应模块教材 + 实验手册中的命令与常见问题 |
| 故障注入 | 提前写好脚本，一键注入多个故障 |
| 学生作业收集 | 共享目录 / 飞书 / 课堂派 |
| 实验快照 | 每个模块开始前给 VM 拍快照 |
| 软件源 | Rocky/Ubuntu镜像源配置模板 + 原始配置备份 + 必需包离线副本 |
| 虚拟化资源 | KVM轻量qcow2、校验值、libvirt网络和OpenStack账号表 |
| 容器镜像 | 课程Registry、固定标签、摘要、离线包、SHA256和镜像清单 |
| 云平台 | OpenStack项目和Kubernetes Namespace、配额、清理规则与回退时段 |
| 跨学期归档 | 保存IP表、配置仓库、数据备份、Dockerfile、Compose、YAML和恢复说明 |

## 五、每节课前检查（5分钟）

```
□ 教师终端可投影
□ 学生 VM 已开机
□ 学生 VM 网络正常（ping 网关）
□ 本节课需要的软件已安装
□ 上次实验残留已清理
```
