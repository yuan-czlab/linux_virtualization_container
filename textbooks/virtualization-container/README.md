## 课程起点

本课程唯一正式起点是《Linux操作系统》实验20验收后的`Linux-L4`。继续使用：

- `rocky-server`：KVM宿主机和Rocky Docker环境；
- `ubuntu-client`：Ubuntu Docker环境和外部客户端；
- `rocky-web`：保留Linux课程成果，按任务启动；
- `~/m1-project`及三机网络、SSH、安全与服务成果。

实验1建立`VC-V0`并生成`~/vc-course/course-env.sh`。后续章节和实验不得绕过该状态文件临时照抄地址、镜像标签或平台参数。

## 学习闭环

每章按照以下顺序使用：

```text
实际问题导入
→ 20—25分钟知识讲解
→ 单条命令或配置观察
→ 自包含短练习
→ 对应实验任务
→ 状态、网络、功能、日志、数据或恢复验收
```

## 命令块约定

- 学生立即执行的命令原则上一个代码块只放一条。
- 可以在批量状态检查、镜像校验和交付验收中使用少量Shell脚本；脚本必须短小、逐步形成，并服务于当前任务。
- 不用大型Shell脚本代替学生亲自完成KVM、Docker、Compose或Kubernetes对象操作。
- 配置文件、Dockerfile、Compose YAML和Kubernetes YAML使用对应语言代码块，不伪装成Shell命令。
- 多步骤项目必须逐步创建输入对象，并在每一步给出观察结果或验收点。
- 第一次出现的路径、变量、镜像、容器、网络和卷必须说明来源。
- 删除虚拟机、镜像、容器、卷或云资源前必须先检查范围。
- OpenStack和Kubernetes使用教师预建平台，不要求学生在本课程搭建集群。
