# Linux操作系统学习通章节

本目录用于学习通逐章发布。完整教材仍保留在`textbooks/01—03`三个模块文件中，学习通版按学生一次完成的学习任务拆分为32章。

## 使用顺序

1. [模块一：Linux基础运维](模块一/README.md)
2. [模块二：网络远程管理与基础防护](模块二/README.md)
3. [模块三：企业服务器部署与综合运维](模块三/README.md)

## 章节编写约定

- 一个Markdown文件对应学习通中的一个章节。
- 学生首次接触的操作采用“目标—单条命令—结果观察—原理解释”。
- 终端命令、配置文件内容和完整Shell脚本必须明确区分。
- 第3.6章以前不把完整Shell脚本作为完成章节的前置要求。
- 配置文件可以使用多行代码块，但必须先给出编辑对象和保存后的检查方法。
- 删除、覆盖、防火墙和服务重启等操作必须先检查范围，并在操作后复测。
- 每章练习使用独立目录；实验成果继续写入`~/m1-project`，避免教材练习污染连续实验状态。

## 命令块约定

一条需要学生立即执行的命令，原则上单独放在一个`bash`代码块中。以下内容可以合理保留多行：

- Nginx、systemd、YAML、仓库等配置文件正文；
- 第3.6章正式讲解的Shell脚本；
- 综合实践阶段已经学过的连续验收命令，但必须注明逐条执行；
- 仅用于展示原理、明确标为“不直接执行”的伪代码。
