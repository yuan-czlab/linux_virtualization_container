## 1.3.1 理解Shell提示符

常见提示符：

```text
[rocky-server@student ~]$
[root@rocky-server ~]#
```

- 第一个`rocky-server`是当前用户。
- 第二个`rocky-server`是主机名。
- `~`代表当前用户家目录。
- `$`通常表示普通用户。
- `#`通常表示root用户。

不要把教材代码块前的说明文字复制到终端。命令中的`$`和`#`如果只是提示符，也不属于命令本身。

## 1.3.2 命令的基本格式

```text
命令 [选项] [参数对象]
```

例如：

```bash
ls -l /etc
```

- 命令：`ls`
- 选项：`-l`
- 参数：`/etc`

Linux命令和文件名通常区分大小写。`File.txt`与`file.txt`是两个不同名称。

## 1.3.3 获取帮助

```text
command --help
man command
type command
which command
```

这里的`command`表示需要查询的真实命令名，不是要求输入的固定单词，后续在学到shell脚本时会系统讲解。

下面使用`ls`、`cd`等真实对象练习。

示例：

```bash
ls --help | less  # 参考ls的使用方式
```

```bash
man ls  # ls的详细使用说明
```

```bash
type cd  # cd的类型
```

```bash
type ls  # ls的类型
```

```bash
which ls
```

`cd`通常是Shell内建命令，因此`which cd`可能找不到；`type cd`能说明它是Shell builtin。

Minimal安装若没有`man`：

```bash
sudo dnf install -y man-db man-pages
```

## 1.3.5 历史、补全和快捷键

| 操作 | 功能 |
|---|---|
| `history` | 查看命令历史 |
| `!!` | 再次执行上一条命令，使用前先确认 |
| `Ctrl+R` | 反向搜索历史 |
| `Tab` | 补全命令或路径 |
| `Ctrl+C` | 中断当前前台命令 |
| `Ctrl+L` | 清屏 |
| `Ctrl+A` / `Ctrl+E` | 移到行首/行尾 |

历史命令可能包含密码或敏感参数，不应把密码直接写在命令行中。

## 1.3.6 引号与Shell展开

使用Shell已经提供的`USER`变量比较双引号和单引号，不依赖前一步自定义变量：

```bash
echo "$USER Linux"
```

双引号会展开变量。再执行：

```bash
echo '$USER Linux'
```

单引号会原样输出字符`$USER Linux`。

```bash
echo file{1..3}.txt      # 花括号展开
```

```bash
touch file{1..3}.txt     # 创建file1.txt file2.txt file3.txt
```

```bash
echo *.txt               # 通配符展开
```

包含空格的路径需要引用：

```bash
mkdir -p "$HOME/My Project"
```

```bash
cd "$HOME/My Project"
```

```bash
pwd
```

```bash
cd ~
```

## 1.3.7 退出状态

程序结束时会返回退出状态。通常0表示成功，非0表示失败：

```bash
ls /etc/passwd
```

```bash
echo $?
```

```bash
ls /path/not-exist
```

```bash
echo $?
```

“没有输出”不等于成功，“有输出”也不等于失败。脚本和自动化工具主要依赖退出状态判断结果。

## 1.3.8 Rocky与Ubuntu常见命令对照

| 任务 | Rocky Linux 9 | Ubuntu 22.04 Desktop |
|---|---|---|
| 更新软件索引 | `dnf makecache` | `apt update` |
| 安装软件 | `dnf install 包名` | `apt install 包名` |
| 查询软件 | `dnf search 关键词` | `apt search 关键词` |
| 查询已安装包 | `rpm -q 包名` | `dpkg -l 包名` |
| 防火墙 | firewalld | ufw常见，也可使用nftables |
| 网络管理 | NetworkManager/nmcli | netplan/systemd-networkd常见 |

### 本章短练习：查询命令并验证退出状态

在Rocky和Ubuntu中分别创建本章独立记录目录：

```bash
mkdir -p ~/course-practice/m1/ch03
```

先查看发行版名称和版本：

```bash
grep -E '^(NAME|VERSION_ID)=' /etc/os-release
```

逐个判断命令类型：

```bash
type cd
```

```bash
type ls
```

```bash
type echo
```

执行一条应当成功的命令：

```bash
ls /etc/passwd
```

立即查看它的退出状态：

```bash
echo $?
```

执行一条故意失败的命令：

```bash
ls /path/not-exist
```

再次立即查看退出状态：

```bash
echo $?
```

最后把本次命令历史保存为学习记录：

```bash
history > ~/course-practice/m1/ch03/command-basics.txt
```

继续完成两个不写入记录文件的交互任务：使用`man ls`找到按修改时间排序的选项；使用Tab补全进入`/etc/systemd/system`，再回到家目录。不要直接照抄完整路径来代替补全练习。
