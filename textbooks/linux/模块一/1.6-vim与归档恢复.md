## 1.6.1 为什么需要文本编辑器

Linux服务器的大量配置使用文本文件。图形界面不可用时，终端文本编辑器是必要工具。

先确认完整的vim命令可用。Rocky Linux最小化安装通常需要安装`vim-enhanced`，Ubuntu使用`vim`包：

Rocky执行：

```bash
command -v vim
```

如果没有输出，再安装Rocky使用的完整Vim软件包：

```bash
sudo dnf install -y vim-enhanced
```

```bash
vim --version | head
```

Ubuntu对照执行：

```bash
command -v vim
```

如果没有输出，再安装Ubuntu使用的Vim软件包：

```bash
sudo apt install -y vim
```

```bash
vim --version | head
```

第2章已经完成国内镜像配置。如果此处仓库不可达，应先排查第2章的IP、网关、DNS和仓库配置，不要跳过错误或从未知网站下载安装脚本。

## 1.6.3 归档与压缩

归档是把多个文件组合成一个文件，压缩是减少数据体积。`tar`常把两者结合：

本章使用固定且容易辨认的练习路径，避免在尚未学习Shell变量时隐藏真实目标。先确认恢复目录没有旧内容：

```bash
ls -ld ~/course-practice/m1/ch06-restore
```

第一次执行应提示目录不存在。然后创建空恢复目录：

```bash
mkdir -p ~/course-practice/m1/ch06-restore
```

记录本次归档路径：

```bash
echo "$HOME/course-practice/m1/ch06.tar.gz" > ~/course-practice/m1/ch06/docs/last-archive.txt
```

记录恢复目录：

```bash
echo "$HOME/course-practice/m1/ch06-restore" > ~/course-practice/m1/ch06/docs/last-restore-dir.txt
```

创建归档：

```bash
tar -C ~/course-practice/m1 -czf ~/course-practice/m1/ch06.tar.gz ch06
```

确认归档文件：

```bash
ls -lh ~/course-practice/m1/ch06.tar.gz
```

常用参数：

| 参数 | 含义 |
|---|---|
| `-c` | 创建归档 |
| `-x` | 解开归档 |
| `-t` | 列出归档内容 |
| `-z` | 使用gzip |
| `-f` | 后面指定归档文件名 |
| `-v` | 显示处理过程，可选 |
| `-C` | 切换到目标目录再操作 |

先检查再恢复：

```bash
tar -tzf ~/course-practice/m1/ch06.tar.gz
```

```bash
tar -xzf ~/course-practice/m1/ch06.tar.gz -C ~/course-practice/m1/ch06-restore
```

```bash
find ~/course-practice/m1/ch06-restore -maxdepth 3 -print
```

不要盲目以root身份解开来源不明的归档文件。归档中可能包含绝对路径、特殊权限或覆盖目标文件的内容。

## 1.6.5 备份必须验证恢复

备份文件存在不等于可恢复。最小验证流程：

```text
创建备份
→ 检查文件非空
→ 列出归档内容
→ 恢复到新目录
→ 对比关键文件
→ 记录恢复时间和问题
```

```bash
diff -ru ~/course-practice/m1/ch06 ~/course-practice/m1/ch06-restore/ch06
```

归档路径和恢复目录分别记录在练习目录的`docs`中，因此重新登录后也可以继续验证。示例使用`tar -C`归档相对路径，恢复结果不依赖具体用户名。

### 本章短练习：修改配置并完成恢复验证

项目工单要求：

6. 把新归档恢复到新的空目录，使用`diff -ru`验证。

完成第1—4项后执行下面的交付命令：

```bash
mkdir -p ~/course-practice/m1/ch06-final-restore
```

```bash
echo "$HOME/course-practice/m1/ch06-final.tar.gz" > ~/course-practice/m1/ch06/docs/last-archive.txt
```

```bash
echo "$HOME/course-practice/m1/ch06-final-restore" > ~/course-practice/m1/ch06/docs/last-restore-dir.txt
```

```bash
tar -C ~/course-practice/m1 -czf ~/course-practice/m1/ch06-final.tar.gz ch06
```

```bash
tar -tzf ~/course-practice/m1/ch06-final.tar.gz
```

```bash
tar -xzf ~/course-practice/m1/ch06-final.tar.gz -C ~/course-practice/m1/ch06-final-restore
```

`diff`无输出且退出状态为0，表示当前项目内容与恢复内容一致。

```bash
test -s ~/course-practice/m1/ch06/docs/initialization-record.md
```

```bash
test -s ~/course-practice/m1/ch06-final.tar.gz
```

```bash
diff -ru ~/course-practice/m1/ch06 ~/course-practice/m1/ch06-final-restore/ch06
```

```bash
echo "restore_compare=$?"
```

`restore_compare=0`才表示当前练习目录和恢复目录一致。
