# Linux操作系统与虚拟化容器技术

> 计算机应用技术专业 · 大二上学期 · 8学分 · 144课时  
> 主线系统：Rocky Linux 9 | 对照系统：Ubuntu Server 22.04 LTS

先修课程：C语言程序设计、Web前端、计算机组成原理、Python程序设计、计算机网络技术、数据库原理及应用（MySQL）。同学期并行课程：交换路由技术（eNSP）与Python自动化运维。

## 课程简介

本课程面向高职计算机应用技术专业（云计算与运维方向），将《Linux操作系统》和《虚拟化容器技术》两门课合并为一条连续课程链，按"Linux基础运维 → 网络与远程管理 → 企业服务部署 → 虚拟化多机环境 → Docker容器化部署 → 综合项目交付"组织教学。

## 五大模块

| 模块 | 名称 | 课时 | 周次 | 核心能力 |
|------|------|------|------|---------|
| M1 | Linux基础运维 | 24 | 第1-3周 | 会操作和管理一台Linux服务器 |
| M2 | 网络、远程管理与基础防护 | 24 | 第4-6周 | 会配置网络、SSH、防火墙、排障 |
| M3 | 企业服务部署 | 24 | 第7-9周 | 会部署Nginx/MySQL/Redis并完成阶段项目 |
| M4 | 虚拟化技术 | 32 | 第10-13周 | 会创建、管理和交付多机虚拟环境 |
| M5 | Docker容器化 | 40 | 第14-18周 | 会用Docker/Compose部署应用并体验K8s操作 |

## 实验手册结构

每篇实验手册包含：

- **实验步骤**（6-8步，命令可复制，带验收点）
- **练习题**（5道，从填空到综合实战）
- **验收标准**（Checklist，学生自检用）
- **常见问题**（真实Q&A，非废话）
- **课后思考**（1-2个拓展问题）
- **清理步骤**（避免环境残留）

## 教学节奏（90分钟/大课）

```
讲 30分钟  →  概念讲解 + 终端演示
练 35分钟  →  学生跟做实验步骤
练 25分钟  →  学生完成练习题
```

## 实验环境

- 宿主机：Windows 10/11 + VMware Workstation 17 Pro
- 主线虚拟机：Rocky Linux 9（最小化安装，2GB内存，30GB磁盘）
- 对照虚拟机：Ubuntu Server 22.04 LTS
- 网络：VMware NAT模式 192.168.200.0/24
