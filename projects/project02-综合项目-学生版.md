# 综合项目：中小型企业基础运维环境搭建与容器化部署

> 对应单元：U66-U72（7次大课 · 14课时）
> 类型：小组（2-3人） | 前置：全部课程内容

## 一、项目名称

**TechCorp 企业官网 + 留言板系统**

## 二、技术架构

```
用户浏览器
  → Nginx(80) 反向代理
    → / → 企业官网静态页面
    → /api/ → Python Flask API(5000)
              → MySQL(3306) 存储留言
              → Redis(6379) 留言计数
```

部署方式：**Docker Compose 一键编排 4 个服务**

## 六、故障排查（3-5个）

教师将从以下类型中各选1个注入：

| 类型 | 示例 |
|------|------|
| 服务故障 | Nginx停止、MySQL停止、Flask进程停止 |
| 网络故障 | 防火墙拦截、端口冲突、DNS错误 |
| 配置故障 | SELinux阻止、权限错误、Nginx语法错误 |
| 容器故障 | 启动失败、网络不通、volume权限 |

每故障记录：**现象 → 排查步骤 → 根因 → 修复 → 验证**
